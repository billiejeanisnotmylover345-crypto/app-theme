# Android setup — Imperial Machina

This repository provides theme artwork, not an installable APK. Android theme formats vary by manufacturer.

## Wallpaper
Open `wallpapers/imperial-machina.svg` in a browser or vector editor. If Gallery cannot display SVG, export it to a 1440 × 3200 PNG, copy it to your phone, and set it as home and lock wallpaper. Position the crest below the clock.

## Launcher
Use a launcher with custom icon, grid and label controls (Nova Launcher or Lawnchair are examples; features vary). Suggested setup: 5 columns, hidden labels, four-icon dock (Phone, Messages, Browser, Camera), dark folders.

## Icons
The SVG sheet is a visual reference, not an installable icon pack. Export individual symbols as transparent square PNGs and assign them using per-app icon editing. Automatic icon replacement requires packaging these assets in an icon-pack APK and mapping installed package names.

## Widgets
A widget app such as KWGT can use:
- Background `#090910` at 80–90% opacity
- Gold borders `#C69A48`
- Ivory text `#E9DFC9`
- Cyan accents `#36E6E0`
- Purple accents `#7546B8`

Use a compact clock/date, slim battery meter and minimal weather line.

## Brand-specific options
Samsung: Galaxy Themes / Good Lock, depending on model and region.
Xiaomi / Redmi / POCO: Themes app support varies by region.
Pixel / Motorola / others: combine wallpaper, launcher and widgets.
